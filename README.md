# Quant Risk Core

A production-grade, highly modular, fully tested Python repository for Quantitative Market & Credit Risk.

## Modules
- **market_risk**: Data preprocessing, GARCH(1,1) Volatility forecasting, VaR / ES estimators (Parametric, Historical, Monte Carlo), EVT Peak-Over-Threshold models, and Basel backtesting (Kupiec, Christoffersen).
- **credit_risk**: Counterparty simulated exposure profiles (EE, EPE, PFE), CVA Engine, Netting agreements, and Margin Period of Risk logic.

## Usage
`pip install -r requirements.txt`
