# Fully-pinned constraints for reproducible installs.
#
# pyproject.toml declares floors and ceilings — the range the library is
# *supported* on. This file pins one exact, known-good point inside that range,
# so a CI run or a redeployed container resolves to the same versions the tests
# were last verified against. A risk number that cannot be reproduced cannot be
# validated, and that includes reproducing the stack that produced it.
#
# Used as a constraints file, not a requirements file:
#
#     pip install -e ".[dev]" -c constraints.txt
#
# Constraints only bound versions of packages that are actually being installed,
# so this single file is safe across platforms and across extras — a Windows-only
# or viz-only entry is simply ignored when it is not in the dependency closure.
#
# Regenerate by resolving the extras into a clean virtualenv and freezing it:
#
#     python -m venv /tmp/lock
#     /tmp/lock/bin/pip install ".[data,viz,dev]"
#     /tmp/lock/bin/pip freeze --exclude-editable
#
# Resolved on: Python 3.13, Windows. `notebook` extra deliberately excluded —
# the jupyterlab widget extension exceeds the Windows MAX_PATH limit, and the
# notebook is not part of any automated run.
#
